# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase 4 UI 形态说明（先于一切表格）：** 本 phase 不改变 Phase 1 确立的**单页、单终端、全视口零铬**形态——无新按钮、无表单、无导航铬。新增可视表面仅两个**瞬态元素**：resize 浮层（`#resize-overlay`）与链接悬停提示（link tooltip）。本 phase 的契约主体是**行为契约**（标题同步 / 超链接 / 剪贴板 / 偏好下发），视觉契约仅覆盖上述两个瞬态元素。

**与 Phase 1 契约的关系：** `01-UI-SPEC.md` 的全部契约（Terminal Options Contract、Terminal Theme、无白闪契约、状态面板契约、Renderer Contract、Page Shell）继续逐字有效，本文件只写**增量与修订**；FE-07 偏好白名单各项的内置默认值即 01-UI-SPEC §Terminal Options Contract 的现值（04-CONTEXT canonical refs 既定）。

**CONTEXT 委托项定稿对照（Claude's Discretion → 本契约落点）：**

| 委托项 | 定稿 | 落点 |
|--------|------|------|
| addon 精确版本号 | unicode11 **0.9.0** / web-links **0.12.0** / clipboard **0.2.0**（npm registry 核实，均 2025-12-22 与 @xterm/xterm 6.0.0 同批发布） | §Addon Contract |
| web-links 修饰键要求 | **单击激活、无修饰键**（xterm 6.0.0 核心源码核实） | §Link Contract |

## Title Sync Contract (CORE-03)

来源：04-CONTEXT D-01/D-02/D-03/D-04（锁定）+ sanitize 截断策略（本契约定稿）。

- **纯前端解析**：`term.onTitleChange`（xterm 内建 OSC 0/1/2 解析）→ 单一写口函数写 `document.title`。服务端 OUTPUT 零拷贝直发，不跑 OSC 状态机；`'T'` TITLE 帧不实现（D-01）。
- **sanitize（逐字契约）**：剥离码点 U+0000–U+001F（C0）、U+007F（DEL）、U+0080–U+009F（C1）→ 按 **code point** 截断前 128 个（`Array.from` 语义迭代，不拆 surrogate pair）。sanitize 结果为空串 → 回退静态默认 `'wesh'`（不清空标签页标题）。
- **写口公式**：`document.title = (ro ? '[ro] ' : '') + sanitized`。`[ro] ` 恒在最前（D-02，防远程内容顶掉只读标识）；rw 无前缀、无品牌后缀（D-04）。
- **初始态**：`<title>wesh</title>`（index.html 既有）；ro 模式下 WELCOME 到达而尚无 OSC 标题时 → `'[ro] wesh'`。
- **ro 前缀写口迁移**：Phase 3 在 WELCOME 分支的 `document.title = '[ro] ' + document.title` 一次性拼前缀写法由本契约的单一写口**取代**（标题变化时前缀不丢）。

## Link Contract (FE-04)

来源：04-CONTEXT D-05/D-06/D-07/D-08（锁定）+ 修饰键与库行为（本契约经源码核实定稿）。

**核实结论（@xterm/xterm 6.0.0 与 addon-web-links 0.12.0 发布产物源码）：**

- **默认正则 = 仅 http/https**（大小写不敏感）：`/(https?|HTTPS?):\/\/[^\s"'!*(){}|\\\^<>`]*[^\s"':,.!?{}|\\\^~\[\]`()<>]/`。**不匹配 ftp/mailto**——以核实到的 0.12.0 源码为准修正 D-05 的描述预期；保持默认正则不动（D-05 本意：不自定义收紧或放宽）。
- **激活 = 单击，无修饰键**：核心链接分派为 mousedown 记录 + mouseup 同链接同位置判定后 `activate()`，路径上无 ctrlKey/metaKey 检查（xterm 官方默认行为即如此；VS Code 的 Ctrl+Click 是其自身实现，非 xterm 默认）。
- **web-links 默认 handler 已满足 D-07 锁定项**：`window.open()` → `opener = null` → `location.href = uri`（等价 `target=_blank rel=noopener`，防 reverse tabnapping）；弹窗被拦截时 `console.warn` 静默。故**不传自定义 handler**。
- **OSC 8 必须设置 `linkHandler`**：不设则库默认回退为 `confirm("Do you want to navigate to …? WARNING: …")` 原生警告框——打断终端流，不可接受。本契约设置 `linkHandler.activate` 走与 web-links 默认 handler 同一形态（`window.open` + `opener=null`）。
- **`allowNonHttpProtocols` 保持默认 `false`**：`javascript:`/`file:` 等非 http(s) OSC 8 链接被库结构性忽略（不渲染为链接）——钓鱼面纵深防御，与 D-06 放行 http(s) OSC 8 不矛盾。
- **hover 展示真实 URL（D-06，ROADMAP 准则 1）**：两类链接统一走 §Link Tooltip Spec——web-links 经 `ILinkProviderOptions.hover/leave`（text 即 URL 本身），OSC 8 经 `ILinkHandler.hover/leave`（text 即真实 uri，可与显示文本不同——钓鱼辨别点）。
- **服务端不做 OSC 过滤**（D-08）：OSC 8 由前端 hover 兜底、OSC 52 由 addon 默认关兜底；`--filter-osc` 开关记 deferred（04-CONTEXT deferred 节）。

### Link Tooltip Spec（新可视元素）

- **结构**：div 创建于 `Terminal.element` 内并加 **`xterm-hover`** class（xterm 官方 tooltip 模式——该 class 使鼠标事件不透传误触发下方其他链接）。
- **内容**：完整 URL 原文，纯文本无前缀（不加 "Open:" 类标签——最小铬、全文可见即钓鱼辨别）。
- **样式**：`position: fixed`；`padding: 4px 8px`；`background: #161616`；`border: 1px solid #2a2a2a`；`border-radius: 4px`；`color: #ffffff`；12px/400/1.5 终端等宽栈；`max-width: 480px`；`word-break: break-all`（长 URL 折行展示全文，**不截断**——截断会破坏钓鱼辨别）；`pointer-events: none`（纯展示，永不阻挡终端交互）；`z-index: 901`。
- **位置**：指针右下方 +8px 偏移；视口右/下边缘不足时向左/上翻转（防溢出视口）。
- **时序**：hover 回调即显、leave 回调即隐，无延迟定时器（终端工具的即手性）。

## Clipboard Contract (FE-05)

来源：04-CONTEXT D-09/D-10/D-11/D-12（锁定）+ 防抖细节（本契约定稿）。

- **选中即复制**：`term.onSelectionChange` → **150ms trailing debounce**（拖动选择期间合并，只写最终选区）→ `term.getSelection()` 非空且与上次写入内容不同 → `navigator.clipboard.writeText(...)`。写入失败（权限/焦点）→ `console.warn` 静默，不弹错不落旧 API。
- **粘贴**：`Ctrl+Shift+V` keydown → `navigator.clipboard.readText()` → `term.paste(text)`（走既有 onData→INPUT 帧链路，保留 bracketed paste 语义；权限由浏览器门控）。读拒绝/不可用 → `console.warn` 静默。**ro 模式不触发读剪贴板**（D-10：无谓权限弹窗）。
- **非安全上下文降级（D-11）**：启动时检测 `navigator.clipboard` 存在性；缺失（明文 HTTP 非 localhost）则选中复制与 Ctrl+Shift+V 整体静默不生效；README 明示剪贴板需 HTTPS/localhost。
- **OSC52（D-12）**：仅当 Welcome prefs 携 `osc52: true`（源自 CLI `--osc52`，默认关）时加载 `ClipboardAddon`，且构造传入**自定义 write-only provider**——`writeText` 委托 `navigator.clipboard.writeText`，`readText` 恒 reject（只写不读，Warp CVE-2025-48725 教训）。`osc52` 不在 URL query 白名单（安全敏感项不允许用户侧绕过服务端意图）。
  - 修订（Phase 4 plan 定稿）：`readText` resolve `''` —— reject 会在 xterm 核心异步 OSC 链 rethrow 成 unhandled rejection；安全姿态相同（04-RESEARCH §Pitfall 4）。执行以 plan 为准。

## Prefs Contract (FE-07)

来源：04-CONTEXT D-13/D-14/D-15/D-16/D-19（锁定）+ 装配顺序与键名映射（本契约定稿）。

- **通道**：Welcome 帧内嵌可选字段 `prefs`（omitempty，P2 D-02 加字段纪律）；`'P'` PREFS 帧占位不实现（v2 再议）。前端在 WELCOME 分支（ro 分支既有处理同处）应用。
- **白名单（10 键 + 1 服务端专有键）**：
  - xterm 视觉选项 8 键：`fontSize` / `fontFamily` / `cursorBlink` / `cursorStyle` / `scrollback` / `lineHeight` / `letterSpacing` / `theme`
  - 前端自定义 2 键（FE-06 开关，非 xterm 选项）：`resizeOverlay` / `confirmBeforeUnload`（布尔）
  - 服务端专有 1 键：`osc52`（仅 `--osc52` 并入 prefs 下发；**不接受** `--client-option` 与 query 设置——D-12/D-16）
  - 内置默认值 = 01-UI-SPEC §Terminal Options Contract 逐项现值（canonical ref 既定）。
- **优先级（D-16 锁定）**：URL query > `--client-option` > 内置默认。
- **装配顺序（逐字契约）**：
  1. Terminal 构造**前**解析 `location.search`：白名单内键 `JSON.parse` 值，成功者记入 `queryKeys` 集合并作为构造选项初值；非法键/非法 JSON **静默忽略 + `console.warn`**（D-16）。
  2. WELCOME 到达：逐项遍历 `prefs`——键在 `queryKeys` 中**跳过**（query 优先）；否则 `term.options.{key} = value` 运行时应用（xterm 原生支持）；`theme` 为完整 JSON 对象**整体替换**（D-19，无预设主题名库）。
  3. 全部应用完 → `fit.fit()` 重算（fontSize/lineHeight/letterSpacing 改变单元格尺寸，D-13 既有决策）→ 既有 onResize→RESIZE 帧链路自动同步服务端。
  4. `resizeOverlay` / `confirmBeforeUnload` 两键写入前端行为开关（非 `term.options`）；`osc52 === true` 触发 §Clipboard Contract 的 addon 加载。
- **query 值形态示例**：`?fontSize=16&cursorBlink=false&fontFamily=%22JetBrains%20Mono%22`（字符串需 JSON 引号，URL 编码；裸 `fontFamily=Menlo` 非合法 JSON → 忽略 + warn）。
- **服务端侧**（非本契约范围，登记边界）：`--client-option key=value` 白名单/JSON 校验失败启动报错（D-15，P3 启动校验矩阵同风格）。

## Auxiliary Interactions (FE-06)

### Resize Overlay Spec（新可视元素）

- **结构**：`<div id="resize-overlay" hidden>` 为 body 直属第三个顶层元素（`#terminal` / `#status` 既有）。
- **内容格式**：`{cols}x{rows}`（ASCII `x`，如 `120x34`；服务端钳制上限 1000×1000 → 内容最长 9 字符，无溢出场景）。无标签文字（ttyd 先例）。
- **样式**：`position: fixed; top: 8px; right: 8px`；`padding: 4px 8px`；`background: rgba(0,0,0,0.6)`；`color: #ffffff`；`border-radius: 4px`；12px/400/1.5 终端等宽栈；`pointer-events: none`；`user-select: none`；`z-index: 900`；`transition: opacity 200ms ease`。
- **行为**：`term.onResize` 触发——更新文本、置 `opacity: 1` 显示、重置隐藏定时器；**600ms 无新尺寸事件后 `opacity: 0` 淡出**（transition 200ms）。仅 **WELCOME 处理完成后**响应（浮层是会话中的 resize 辅助，不是启动尺寸指示器；onopen 初次 fit 不触发）。
- **开关**：默认**开**（D-17）；prefs/query `resizeOverlay: false` 关闭（关闭时不创建/不显示）。
- **ro 模式**：同样显示（ro 下 RESIZE 帧本就放行，P2 协议基线）。

### 离开页面前确认（beforeunload）

- **默认开**（D-18，ro 同启）：注册 `beforeunload` handler 调 `preventDefault()` 触发浏览器标准确认框。**无自定义文案**——现代浏览器一律忽略自定义文案（D-18 注明），不写字面量。
- **会话终结后解除**：WS `onclose` 任意路径（含状态面板三态展示后）移除该 listener——"Session ended" 后关标签页不应再被拦截。
- **开关**：prefs/query `confirmBeforeUnload: false` 关闭。Phase 6 重连落地后开关保留（D-18）。

## Interaction Contract

01-UI-SPEC §Interaction Contract 逐字有效（启动聚焦、resize 回路、键盘门控、滚动）。本 phase 新增/修订：

- **标题同步**：OSC 0/1/2 → sanitize → 单一写口 `document.title`（§Title Sync Contract）。
- **链接**：hover 显示真实 URL tooltip；单击（无修饰键）新标签页打开（noopener 形态）；非 http(s) OSC 8 链接不响应（§Link Contract）。
- **选中即复制**：最终选区 150ms 防抖后写系统剪贴板，静默降级（§Clipboard Contract）。
- **粘贴**：`Ctrl+Shift+V` 异步读剪贴板走 `term.paste()`；ro 不读；权限拒绝静默（§Clipboard Contract）。
- **resize 浮层**：resize 期间右上角 COLSxROWS，静止 600ms 后淡出（§Resize Overlay Spec）。
- **离开确认**：默认拦截，会话终结后放行（§Auxiliary Interactions）。
- **偏好生效**：query 先于构造、Welcome prefs 到达后应用并 fit 重算（§Prefs Contract）。
- **本 phase 明确没有的交互**：无右键菜单、无重连按钮（Phase 6 CORE-05）、无 ro/rw 分享链接 UI（Phase 5 MULTI-05）、无设置面板（白名单经 CLI/query 通道，无 GUI）、无移动端专项 UI（deferred）。
