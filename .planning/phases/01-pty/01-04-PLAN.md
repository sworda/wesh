    新建 `internal/pty/reap_darwin.go`（`//go:build darwin`），照 RESEARCH 行 254-324 骨架落地：
    1. `type exitWatcher struct { kq int; mu sync.Mutex; subs map[int]chan<- struct{} }`——进程级共享：一个 kqueue fd、一个 loop goroutine，N 会话共用（零每会话线程，D-14）。
    2. `func newExitWatcher() (*exitWatcher, error)`：`unix.Kqueue()` 创建，起 `go w.loop()`。
    3. `func (w *exitWatcher) watch(pid int) (<-chan struct{}, error)`：缓冲 1 的 chan 登记进 subs；`unix.Kevent(w.kq, ev, nil, nil)` 非阻塞注册——Kevent_t 字段：Ident=uint64(pid)、Filter=unix.EVFILT_PROC、Flags=unix.EV_ADD|unix.EV_ONESHOT、Fflags=unix.NOTE_EXIT|unix.NOTE_EXITSTATUS（EV_ONESHOT 触发一次即自动注销）。
    4. `func (w *exitWatcher) loop()`：`unix.Kevent(w.kq, nil, events, nil)` 阻塞取事件；EINTR continue；其他错误 return（Phase 1 进程级致命即可，注释记 TODO Phase 8 接 slog）；只对 Fflags 含 NOTE_EXIT 的事件派发给 subs[pid]（发送前从 map 删除）。
    5. 会话侧签名与 linux 统一（PATTERNS 注意 4——调用点零平台分支）：`func awaitExit(cmd *exec.Cmd) error`，内部经包级单例 watcher（sync.Once 懒初始化）：`<-exited` 后 `return cmd.Wait()`——Wait 是唯一收割者（wait4 收割 + *exec.ExitError 退出码完整），watcher 只做"早知"。单例初始化失败时直接 `return cmd.Wait()`（兜底不致命）。
    6. 文件头注释登记：禁手写 pidfd_open / SIGCHLD+WNOHANG 手动 reap（会与 Wait 争收割权，RESEARCH 修正决议 行 488）；兜底预案——若 Task 2 的竞态测试裁决 kqueue 不补发僵尸事件，本文件的 awaitExit 退化为直接 cmd.Wait()，watcher 代码以 build tag 保留待 Phase 5 多会话时重估。
